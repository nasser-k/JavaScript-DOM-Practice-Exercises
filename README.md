# JavaScript DOM Manipulation Mini Projects

This repository contains a collection of JavaScript mini-projects focused on DOM manipulation and interactive web components. These projects demonstrate various aspects of web development including event handling, state management, and local storage.

## Set 1: Basic DOM Manipulation

### 1. Text Style Changer
A web component that allows users to modify text appearance using dropdown menus.
- Features:
  - Font size selection
  - Color selection
  - Font family selection
  - Real-time preview

### 2. Click Counter
A simple counter that tracks the number of times a button is clicked.
- Features:
  - Click tracking
  - Counter display
  - Clean UI

### 3. Password Toggle
A password input field with show/hide functionality.
- Features:
  - Password visibility toggle
  - Checkbox control
  - Secure password input

### 4. Character Counter
A text area with real-time character counting functionality.
- Features:
  - 200 character limit
  - Real-time updates
  - Visual feedback when nearing limit
  - Warning style when low on characters

## Set 2: Interactive & Logic Driven Components

### 1. Dynamic List Manager
An interactive list management system.
- Features:
  - Add new items
  - Edit existing items
  - Delete items
  - Real-time updates
  - Clean UI/UX

### 2. Filter Table Rows
A searchable table with dynamic filtering capabilities.
- Features:
  - Real-time search
  - Case-insensitive filtering
  - Multiple column search
  - Responsive design

### 3. Image Carousel
A responsive image slideshow with navigation controls.
- Features:
  - Next/Previous navigation
  - Automatic slideshow
  - Indicator dots
  - Smooth transitions
  - Responsive design

### 4. Theme Switcher
A light/dark mode toggle with persistent state.
- Features:
  - Light/Dark mode toggle
  - LocalStorage persistence
  - System preference detection
  - Smooth transitions
  - CSS variables for theming
